# Data Display Guide - Parallel RAG with PARSL 📊

**Purpose**: Complete guide to data elements displayed in the parallel RAG demo  
**Status**: ✅ **FULLY IMPLEMENTED**

---

## 🎯 OVERVIEW

The parallel RAG demo displays comprehensive data for each query, including:

1. ✅ **Original Query** - User's input
2. ✅ **Enhanced Prompt** - Generated by PARSL worker
3. ✅ **Worker ID** - Unique identifier for the PARSL worker
4. ✅ **Final Response** - Complete workflow output (optional)

---

## 📊 DATA ELEMENTS DISPLAYED

### 1. Original Query

**What**: The user's original input query  
**When**: Displayed at the start of each query processing  
**Format**: Plain text

**Example**:
```
📥 Original Query:
   What are the key mechanisms of viral membrane fusion?
```

### 2. Enhanced Prompt ⭐

**What**: The enhanced/optimized query generated by the PARSL worker  
**When**: After PARSL processing completes  
**Format**: JSON object with detailed enhancement information

**Example**:
```
✨ Enhanced Prompt (Generated by PARSL Worker):
   {
     "enhanced_query": "What are the primary processes, key mechanisms,
     and fundamental principles of viral membrane fusion? Can you provide
     information on the molecular interactions, fusion proteins, and the
     role of envelope glycoproteins in this process?",
     
     "search_terms": [
       "primary processes",
       "key mechanisms",
       "fundamental principles",
       "viral membrane fusion",
       "molecular interactions",
       "fusion proteins",
       "envelope glycoproteins"
     ],
     
     "context_additions": "The query is seeking information on the
     biological and molecular mechanisms involved in the process of viral
     membrane fusion. This includes the role of specific proteins and
     molecular interactions.",
     
     "enhancement_rationale": "The original query was expanded to include
     synonyms and related terms such as 'primary processes', 'fundamental
     principles', 'molecular interactions', and 'fusion proteins'. This
     will help to capture a wider range of relevant documents.",
     
     "confidence_score": 0.95
   }
```

**Components**:
- `enhanced_query`: The improved query text
- `search_terms`: Key terms extracted for search
- `context_additions`: Additional context added
- `enhancement_rationale`: Explanation of enhancements
- `confidence_score`: Confidence in the enhancement (0-1)

### 3. Worker ID ⭐

**What**: Unique identifier for the PARSL worker that processed the query  
**When**: Displayed with each query result  
**Format**: `worker_<8-char-hex>`

**Example**:
```
👷 PARSL Worker ID: worker_bb4abab8
```

**Purpose**:
- Track which worker processed each query
- Verify parallel processing
- Debug performance issues
- Monitor worker utilization

### 4. Final Response (Optional)

**What**: The complete response from the entire RAG workflow  
**When**: After full workflow processing completes  
**Format**: Text or JSON depending on workflow configuration

**Example**:
```
📤 Final Response (from complete workflow):
   Based on the analysis of viral membrane fusion mechanisms, the key
   processes include: 1) Viral attachment to host cell receptors, 2)
   Conformational changes in fusion proteins, 3) Membrane hemifusion,
   and 4) Pore formation and expansion...
```
